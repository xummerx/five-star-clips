Privacy policy

Five Star Clips Uploader · effective 15 November 2026

Who uses it

Only the owner of the Five Star Clips YouTube channel, on the owner's own computer. The tool has no other users and no website login.

Google user data it accesses

  • An OAuth token for the owner's own Google account, with the youtube.upload and youtube.readonly permissions.
  • The channel ID, and the IDs, titles and processing status of the videos the tool uploaded.

How it is used

Only to upload the owner's clips to the owner's channel and to check that those uploads are processed and public. Nothing else.

Where it is stored

Only on the owner's computer, in a local file that only the owner can read. It is sent to no server other than Google's own APIs. There are no analytics, cookies or ads.

Sharing

Google user data is never sold, shared or transferred to anyone.

Google API Services User Data Policy

Five Star Clips Uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the tool's local files removes everything it stored.

Contact

Open an issue at github.com/xummerx/five-star-clips/issues.
